# Provider Dashboard & Theme 디자인 명세

## 1. 목적

Compact 사용량 화면에서 Codex와 Claude 상태를 한눈에 비교할 수 있게 하고, 경고 정보는 숫자에 집중시키며, 사용자가 설정에서 라이트·다크 테마를 직접 선택할 수 있게 한다.

## 2. 디자인 원칙

- Codex와 Claude는 동일한 정보 구조를 사용하되, 공급자 식별 색상은 카드의 작은 표식과 아이콘에만 제한한다.
- 사용량 위험도는 막대의 다채로운 색이 아니라 잔여 퍼센트 숫자의 색과 굵기로 전달한다.
- 기본색, 공급자색 2개, 상태색 2개만 사용한다. 같은 의미에는 항상 같은 색을 쓴다.
- 색상만으로 의미를 전달하지 않는다. 상태 문구, 숫자, `aria` 속성을 함께 제공한다.
- 테마가 바뀌어도 정보 우선순위, 대비, 공급자 구분은 유지한다.

## 3. Compact 화면 구조

### 3.1 공급자 카드 배치

- Codex 카드와 Claude 카드를 기본 창에서 좌우 2열로 배치한다.
- 두 카드의 너비와 내부 정보 순서는 동일하게 유지한다.
- 공급자가 하나만 표시되면 해당 카드가 전체 폭을 사용한다.
- 창 폭이 콘텐츠를 읽기 어려운 수준으로 줄어드는 경우에만 1열로 전환한다.
- 기본 Compact 창은 `560 x 340px`, 최소 크기는 `340 x 320px`로 조정한다.
- `500px` 이상은 2열, `499px` 이하는 1열로 전환한다. 높이 기반 밀도 규칙은 열 수를 바꾸지 않는다.

### 3.2 카드 헤더와 아이콘

- 각 카드 좌측 상단에 단색 SVG 아이콘과 공급자명을 배치하고, 본문 시작에 공급자별 메시지를 한 번만 표시한다.
- Codex는 청록 계열, Claude는 브랜드의 warm orange 계열 식별색을 사용한다.
- Codex는 OpenAI 공식 브랜드 가이드가 제공하는 Blossom 원본 형태를 사용한다.
- Claude는 `claude.ai`를 출처로 등록한 Simple Icons의 Claude glyph를 사용하고 제3자 고지에 출처와 라이선스를 기록한다.
- SVG는 `20 x 20px`, `currentColor`, `aria-hidden="true"`로 제공하고 인접한 텍스트 공급자명을 접근 가능한 이름으로 사용한다.
- 기존 연결 상태는 헤더 우측에 짧게 표시한다.

### 3.3 공급자별 메시지

- 공통 결정 메시지는 제거하고 각 카드 하단에 공급자별 결정 메시지 박스를 둔다.
- 메시지 제목은 해당 공급자의 최우선 alert에서, 본문은 해당 공급자의 최우선 recommendation에서 가져온다.
- 예: `Codex 리셋 전 소진 가능성` / `Codex 주간 사용 속도를 약 40% 낮추면 다음 리셋까지 한도를 유지할 가능성이 커집니다.`
- 오래된 데이터는 분석 권고 대신 최신 사용량 확인 요청을 우선 표시한다.

| 상태 | 메시지 규칙 |
| --- | --- |
| 미연결·수집 전 | `사용량을 확인하려면 연결 상태를 확인하세요.` |
| 잔여 10% 이하 | `한도에 거의 도달했습니다. 새 작업을 줄이세요.` |
| 잔여 50% 이하 | `사용 속도를 확인하고 중요한 작업을 우선하세요.` |
| 잔여 51% 이상 | `현재 사용 여유가 있습니다.` |

### 3.4 숫자와 막대

- 잔여 퍼센트 숫자는 최소 `18px`, `font-weight: 800`로 표시한다.
- 잔여율이 `50% 이하`면 경고색, `10% 이하`면 위험색을 적용한다.
- 51% 이상과 수집 전 숫자는 기본 전경색을 사용한다.
- 숫자 요소의 `data-level`은 `neutral`, `warning`, `critical` 중 하나이며 null·비정수·범위 밖 값은 `neutral`로 처리한다.
- 막대 트랙과 채움은 테마별 중성 회색의 명암 차이만 사용한다.
- 공급자 식별색이나 위험도색을 막대 채움에 사용하지 않는다.
- `5시간`·`세션`에는 짧은 미니 스케일, `주간`에는 전체 폭 미니 스케일을 함께 표시해 단기 한도가 장기 범위 안에 포함되는 관계를 빠르게 비교할 수 있게 한다.
- 리셋 시각과 마지막 갱신 시각은 한 줄의 메타 정보로 묶어 카드 높이를 줄인다.

## 4. 색상 체계

### 4.1 의미 토큰

| 역할 | 다크 | 라이트 |
| --- | --- | --- |
| 배경 | 짙은 청회색 | 차가운 흰색 |
| 패널 | 배경보다 밝은 청회색 | 흰색 |
| 기본 텍스트 | 밝은 회색 | 짙은 청회색 |
| 보조 텍스트·막대 | 중성 회색 | 중성 회색 |
| Codex 식별 | 청록 | 진한 청록 |
| Claude 식별 | warm orange | 짙은 orange |
| 50% 이하 | 호박색 | 짙은 호박색 |
| 10% 이하 | 적색 | 짙은 적색 |

- 공급자색은 `.provider-mark`, `.provider-icon`, `.provider-name`에만 사용한다.
- 경고·위험색은 퍼센트 숫자와 필요한 최소 상태 표식에만 사용한다.
- 카드 배경 전체를 공급자색이나 경고색으로 채우지 않는다.

## 5. 테마 설정

- 설정 화면의 `앱 설정` 영역 첫 항목에 `id="theme-select"`인 네이티브 select를 추가한다.
- 선택지는 `다크`, `라이트` 두 가지다.
- 선택 즉시 현재 설정 창과 열려 있는 다른 앱 창에 반영한다.
- 선택값은 공통 origin의 `localStorage` 키 `ai-usage-monitor-theme`에 보존한다.
- 공통 `theme.js`를 각 HTML의 stylesheet보다 먼저 로드해 저장값을 `data-theme`에 적용하고 첫 페인트의 테마 깜빡임을 막는다.
- 열린 창은 브라우저 `storage` 이벤트를 구독하며, 설정 창은 저장 직후 현재 문서에도 직접 적용한다.
- 저장값이 없거나 `light`, `dark` 외 값이면 `dark`로 복구한다.
- 초기값은 기존 사용자 경험을 유지하기 위해 `다크`다.
- `compact`, `setup`, `insights`, `details`, `update` 화면 모두 공통 테마 초기화와 토큰을 사용한다.

## 6. 접근성과 반응형

- 라이트·다크 모두 일반 텍스트 4.5:1, 큰 텍스트 3:1, 포커스·아이콘·필수 UI 경계 3:1 이상을 목표로 한다.
- 퍼센트 임계값은 색상 외에 숫자 자체와 공급자 메시지로도 해석할 수 있어야 한다.
- 키보드 포커스 링은 각 테마에서 분명해야 한다.
- 2열에서 긴 속도·리셋 문구는 잘림 대신 필요한 경우 줄바꿈한다.
- 좁은 창에서는 1열로 전환하며 기능과 읽기 순서를 유지한다.

### 6.1 Insights 생존 판단 카드

- 최우선 한도의 판정, 예상 소진과 리셋 비교, 시간당 사용 속도, 행동 제안을 하나의 카드에 배치한다.
- 제목은 `현재 속도면 리셋보다 N 먼저 소진`처럼 결과를 먼저 전달하고, 배지는 필요한 감속률을 표시한다.
- 시간당 사용 속도는 별도 막대 두 개가 아닌 단일 막대로 표시한다. 막대 끝은 현재 속도, 수직 기준선은 리셋까지 허용되는 속도다.
- 현재 속도가 허용 속도를 넘으면 막대를 위험색으로 표시하고 `현재가 허용 속도의 N배`를 함께 제공한다.
- 반복되는 수집·리셋 정보와 장문의 분석 문장은 접거나 축약해 카드의 세로 길이를 줄인다.

### 6.2 표시 언어

- Setup에서 `한국어`와 `English` 중 하나를 선택할 수 있다.
- 선택값은 로컬에 저장하고 Compact, Insights, Details, Setup, Update 화면에 공통 적용한다.
- 열린 창은 언어 변경을 감지해 다시 렌더링하며 날짜와 숫자 형식도 선택 언어의 로케일을 따른다.
- 지원하지 않는 저장값은 기본 언어인 한국어로 복구한다.

## 7. 구현 범위

- `compact.html/css/js`: 2열 공급자 카드, 실제 브랜드 아이콘, 공급자별 분석 메시지 박스, 퍼센트 강조, 중성 막대.
- `setup.html/css/js`: 테마 선택 UI.
- Setup의 도구 연결 영역은 Compact와 동일하게 Codex 좌측·Claude 우측의 2열 구조를 사용하고, 좁은 화면에서만 1열로 전환한다.
- Claude `statusLine`은 Claude 인증 후 자동 연결하고 Setup UI에서는 숨긴다. 기존 사용자 `statusLine` 명령이 있으면 자동 교체하지 않고 그대로 보존한다.
- 공통 테마 모듈 및 각 화면 CSS: 저장·복원·창 간 동기화와 라이트 토큰.
- Tauri Compact 기본·최소 크기: 2열 기본 레이아웃에 맞게 조정.
- UI 정적 테스트: 구조, 임계값, 테마 저장 계약, 모든 화면의 테마 적용 여부 검증.

## 8. 완료 조건

1. 기본 Compact 창에서 Codex와 Claude 카드가 좌우로 보인다.
2. 한 공급자만 활성화하면 카드가 전체 폭을 사용한다.
3. 50%와 10% 경계에서 퍼센트 숫자 클래스와 메시지가 정확히 바뀐다.
4. 막대는 모든 잔여율에서 중성 명암만 사용한다.
5. 두 카드의 아이콘·표식·메시지로 공급자를 즉시 구분할 수 있다.
6. 설정에서 라이트·다크를 선택하고 앱을 다시 열어도 선택이 유지된다.
7. 모든 앱 화면이 선택한 테마를 사용하며 기존 UI·Rust·릴리스 테스트가 통과한다.
8. 각 meter의 `aria-valuenow`·`aria-valuetext`가 숫자와 일치하고 공급자 메시지는 `aria-live="polite"`로 갱신된다.
